<h2 align="center">550W / MOSS</h2>

![550W MOSS in GRUB at 1080p](https://raw.githubusercontent.com/iskshadow195563/550w-moss-grub/main/docs/preview-1080p-ubuntu.png)

<p align="center"><a href="https://github.com/iskshadow195563/550w-moss-grub">Repository</a> | <a href="https://github.com/iskshadow195563/550w-moss-grub#readme">Documentation</a> | <a href="https://github.com/iskshadow195563/550w-moss-grub/releases/tag/v1.0.0">Releases</a></p>

Unofficial MOSS fan theme for an existing Ubuntu / Windows 11 dual-boot setup. Includes a live menu and countdown, CJK fonts, red selection borders, OS icons, 720p / 1080p / 1440p / 4K layouts, and an Ubuntu installer with backup, validation and rollback.

Artwork disclosure: the background is AI-edited from a supplied reference and scales from 1672×941; 4K refers to the layout. A general code/artwork license is not currently specified; the Noto-derived fonts include SIL OFL 1.1. See the project README for details before redistributing assets.
